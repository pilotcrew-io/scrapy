========
Exemples
========

La meilleure façon d'apprendre est de passer par des exemples, et Scrapy ne
fait pas exception. C'est pourquoi il existe un projet Scrapy d'exemple appelé
quotesbot_, que vous pouvez utiliser pour vous exercer et en apprendre
davantage sur Scrapy. Il contient deux spiders pour
https://quotes.toscrape.com : l'un utilise des sélecteurs CSS, et l'autre des
expressions XPath.

Le projet quotesbot_ est disponible à l'adresse suivante :
https://github.com/scrapy/quotesbot. Vous pouvez trouver plus d'informations à
son sujet dans le README du projet.

Si vous êtes à l'aise avec git, vous pouvez récupérer le code (checkout).
Sinon, vous pouvez télécharger le projet sous forme de fichier zip en cliquant
`ici <https://github.com/scrapy/quotesbot/archive/master.zip>`_.

.. _quotesbot: https://github.com/scrapy/quotesbot
